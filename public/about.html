SmartFilter Help

SmartFilter-UI is a modern web application for molecular filtering and analysis using SMARTS patterns. It enables filtering of compound libraries against well-known substructure filters and visualization of matched substructures directly in the browser.

Modes of Operation

  • Filter Mode – Filter a set of molecules against selected filters. Inspect failed compounds and their matching patterns.
  • Analyze One Molecule Mode – Test a single molecule against all filters. View all matches and highlighted atoms interactively.

Supported SMARTS Sets

  • Blake – From James Blake (Array Biopharma). Originally published in SLN format and translated to SMARTS.
  • Glaxo – Includes unsuitable leads, unsuitable natural products, and reactive subsets. Optional subsets include electrophilic, nucleophilic, acids, and bases.
  • ALARM NMR – Derived from Abbott’s method for detecting reactive false positives.
  • Oprea – General multi-objective library fitness filters by Tudor Oprea.
  • Toxicity – Developed by Oleg Ursu, based on toxicophores from published sources.
  • MLSMR – NIH Roadmap screening filters (original and relaxed MLSCN versions).
  • PAINS – Pan-Assay Interference Compounds (Baell & Holloway, 2010), translated into SMARTS.

Note on Standardization:
SMARTS or any substructure filtering depends on valence standardization. For example:

  • Nitro groups should be represented as -N(=O)=O (not charge-separated).
  • Carboxylic acids should be protonated -C(=O)[OH] (not deprotonated).

The app applies basic valence normalization before matching to accommodate non-standardized input.

Web App Features

  • Show Matches – Display all SMARTS patterns matched for each molecule.
  • Include Passes / Fails – Control whether successful or failed molecules appear in the output.
  • Normalize Molecules – Optionally normalize nitro groups, carboxylic acids, etc., via SMIRKS rules.
  • Strict Mode – Enforce strict SMARTS parsing (errors fail instead of being ignored).
  • Batch Processing – Supports thousands of molecules (default max: 5000; view limit: 100).
  • Visualization – Molecules rendered with RDKit.js, with substructures highlighted inline.

Technology

  • Frontend: React + TypeScript + Vite
  • Cheminformatics: RDKit.js (WASM build of RDKit)
  • Styling: TailwindCSS + ShadCN/UI
  • Deployment: Docker + Nginx frontend, SmartFilter API backend

Unlike earlier versions (which used ChemAxon JChem), this UI relies entirely on open-source RDKit.js for substructure search, rendering, and normalization.
